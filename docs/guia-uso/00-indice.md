# Guia de uso del sistema interno AILE

Base documental para directores, autoridades y personas autorizadas a usar el sistema.

Estado relevado sobre el funcionamiento actual del sistema al 11 de marzo de 2026.

## Para que sirve esta guia

Esta guia esta pensada para personas que no usan sistemas todos los dias.

La idea es explicar:

- para que existe el sistema,
- quien lo usa,
- que puede hacer cada persona segun su rol,
- que hace cada modulo,
- y como recorrer el sistema sin lenguaje tecnico.

## Nota importante

No todas las personas ven lo mismo.

El sistema muestra u oculta modulos segun:

- el nivel de acceso general de la persona,
- su cargo dentro de AILE,
- y los permisos que tenga asignados.
